# Transport-Triggered Architecture CPU

This is an attempt at a TTA CPU using Digital components. The eventual goal will be to translate this to relays.

See [this project](https://dslik.github.io/ttam/index.html) for some information on TTA. Also [this YouTube video](https://www.youtube.com/watch?v=q6ytRHaTEXI) and the [MAXQ family of microprocessors](https://www.analog.com/media/en/technical-documentation/user-guides/maxq-family-users-guide.pdf).4
